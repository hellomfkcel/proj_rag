## 真正决定学习速度的是什么

```
学一个新东西的实际时间 =

  新知识本身的复杂度
  ─────────────────────────────
  你已有的相关知识密度

  分母越大，学得越快
  分母是你过去所有经历积累的
  不是"努力"能短期堆出来的
```

```
  Agent 的核心问题自然就看见了
```
