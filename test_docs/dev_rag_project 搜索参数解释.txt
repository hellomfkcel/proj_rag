  ---
  典型场景调参

  搜"The function of vllm" → Alpha 0.3, Mode=keyword_only（英文术语查精确命中）

  搜"数字人是什么有哪些应用场景" → Alpha 0.85, Mode=hybrid（需要语义理解）

  长文档精细回答 → Synthesis=refine, Top K=20, Rerank Top K=10

  不想 LLM 瞎编 → Sim. Threshold=0.5（筛掉语义不相关的 chunk，宁可少答也不错答）
